# JOUR628 Data Visualization

## This is the repo for my data viz class at Merrill College of Journalism. Each folder has all of the materials needed for a lab session covering a new method to visualize data.

Course Overview:
This class is focused on the visualization of data for journalistic storytelling. You'll learn data visualization theory, best practices and how to visualize data in the service of journalism. You will learn how the human mind processes visual information and how to encode data for easy interpretation. You will learn what makes a visualization effective and ethical. And you will learn how to create visualizations of data using a variety of methods and tools.

Each student will create a number of visualizations and infographics over the course of the semester and will produce a piece of journalism powered by data visualization for their final project.

The class will include lectures, self-directed learning modules and in-class laboratory sessions. This is a very hands-on class; you should expect to be coding, designing graphics and using digital tools during and between classes.

 

Learning outcomes:
Students will learn to:

Understand fundamental data visualization concepts and principles.
Select the best chart type and visual encoding for a given set of data.
Apply graphic design principles to the creation of data visualizations, including the use of contextual type and color, graphic design fundamentals and gestalt principles.
Utilize data visualization tools and techniques to visualize data in a straightforward, accurate and visually compelling manner.
Design and build interactive data visualizations using code and open-source software.
Understand the ethics of journalistic data visualization and how to present data in an accurate and truthful manner.
Critically evaluate professional visualizations and data-driven news stories.
Apply data visualization techniques to journalism and storytelling.
